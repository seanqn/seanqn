### Pincer
A Python developer tool for inspecting LLM agent execution traces. Integrates with the OpenAI Agents SDK to capture structured events and provides a terminal debugger for inspecting model calls, tool invocations, and failures.

&nbsp;

Debugger Output:


https://github.com/user-attachments/assets/dd8b4054-16ca-435e-8cad-329d450b03bb

Debugger currently holds a few options:
- [list]: the default output after running the debug command on a trace file
- [select \<step\>]: selects a step from list output for specific information for that trace step
- [details]: provide additional information
- [previous]/[next]: traverses trace steps individually

### Academic Projects
Several repos showcase some custom Abstract Data Types, ADT optimizers, and algorithms implemented into a subset of these. A few are:
- Binary Search Tree Validator: Validates whether a BT search was correct
- AVL Tree Nth Largest: Searches an AVL (Adelson-Velsky Landis) Tree with self-rotating behavior and tracks the largest node value
- List/Matrix Graph: ADT for each; list uses a linked behavior and matrix a 2D array for directed graph traversal
